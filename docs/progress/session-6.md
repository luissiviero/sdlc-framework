## Choices made where the pack left it open (continuing session 5's numbering)
84. **A rehearsal files whatever the series says** (the workflow input's own words): a forced tier on an empty series still files, with a null latest point, so the loop can be rehearsed on a project whose CI has no counted run yet.
85. **The default branch is told, not guessed**: the workflows pass `SDLC_DEFAULT_BRANCH` (`github.event.repository.default_branch`) to every step that reads "the default branch's" `bands.yaml` or `sdlc.yaml` or starts a branch from it; the guess stays as the by-hand fallback, remote-tracking first.
86. **The rehearsal PRs are closed without a comment**: every forced finding shares the signature `detect|<metric>|forced`, so a dismissal would mute the next rehearsal for a window; a close without a comment abandons and dismisses nothing (decision 25's reading (ii)), which is what a rehearsal wants.
87. **The sample gets a plain CI workflow** (its PR #24): the framework's own workflows are excluded from the metric by design, so without one the project's failure rate has no observation at all; every project should carry one, and `/sdlc-init` could say so in its report (not built).
88. **The shakedown method**: a branch of the sample whose detect workflow checks out the framework at the branch under test, dispatched with `ref: <that branch>`; fixes are live-tested before the tag exists. The pin step still runs and its output is unused for the checkout ref only.
