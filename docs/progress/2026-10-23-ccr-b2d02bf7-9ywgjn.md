## The owner's choices
259. **Each session writes its record as its own file** (the owner, 2026-10-23, this session's chat). The record is `docs/progress/<YYYY-MM-DD>-<branch>.md`, named as the session file; a branch restarted after its PR merged adds a suffix. `docs/PROGRESS.md` becomes a fixed page that points to the folder, and `docs/progress/index.md` lists only the records written before this choice. With it come two rules in `HANDOFF.md`:
    - a conflict in a generated index is resolved by running its task again, never by hand;
    - a build PR annotates only its own ROADMAP rows, and an annotation across other candidates' rows goes in a documentation PR of its own.
