## 51. Facts read on 2026-10-19 for ROADMAP R7: how a sub-agent's model is chosen, what the opus alias resolved to in CI, and the reviewer's invented time

### cli
- **The model field takes an alias, a full id or `inherit`** (sub-agents reference, "Choose a model", read 2026-10-19): "**Model alias**: use one of the available aliases: `sonnet`, `opus`, `haiku`, or `fable`"; "**Full model ID**: use a full model ID such as `claude-opus-5-5` or `claude-sonnet-5`. Accepts the same values as the `--model` flag"; "**inherit**: use the same model as the main conversation".
- **The resolution order** (same section): "1. The per-invocation `model` parameter 2. The subagent definition's `model` frontmatter, where `inherit` selects the main conversation's model 3. The `CLAUDE_CODE_SUBAGENT_MODEL` environment variable, when you set it to a model alias or model ID 4. The main conversation's model". NOTES §11c's order stands.
- **Two cases where an alias runs on the session's own model** (same section): "In two cases, a family alias such as `opus` in the per-invocation parameter or the frontmatter resolves to the main conversation's model instead of the version the alias points to": when "The main conversation's model belongs to that family" ("the subagent runs on the main conversation's exact model, including any `[1m]` suffix"), and on a provider other than the Anthropic API when Claude Code cannot tell the session's family, a case that "doesn't apply when you set `ANTHROPIC_DEFAULT_OPUS_MODEL`".
- **The alias pins** (model configuration and environment variables pages, read by a docs sub-agent of this session, 2026-10-19): "`ANTHROPIC_DEFAULT_OPUS_MODEL` | The model to use for `opus`, or for `opusplan` when Plan Mode is active"; "`ANTHROPIC_DEFAULT_FABLE_MODEL` | The model to use for `fable`, …"; "Each value must be a full model name, or the equivalent identifier for your API provider". The pages say "the 1M context window applies to all usage of the pinned alias, including … subagents whose `model` frontmatter names the alias". **Not read:** from which CLI version `ANTHROPIC_DEFAULT_FABLE_MODEL` exists; whether 2.1.278, the pin, honours it.
- **`--model` takes an alias or a full name** (CLI reference): "a model alias such as `sonnet`, `opus`, `haiku`, or `fable`, or a model's full name"; a mistyped value is not checked up front and fails on the first request.
- **The Agent tool's per-invocation model is one of four aliases** (verified, this session's own Agent tool definition on Claude Code 2.1.304: `"model": {"enum": ["sonnet", "opus", "haiku", "fable"]}`). The docs do not say whether a full id is accepted there. So a phase command cannot start a sub-agent on `claude-opus-5-5` by name; it passes `opus`, and the alias resolves as above.
- **The current model ids** (the claude-api skill's model table, cached 2026-10-06): Claude Opus 5.5 `claude-opus-5-5` ($4 / $20 per million input / output tokens), Claude Fable 5.1 `claude-fable-5-1` ($10 / $50), Claude Sonnet 5.5 `claude-sonnet-5-5` ($2 / $10), Claude Haiku 5.5 `claude-haiku-5-5`.
