# Progress

This page is fixed. It held the newest session record until choice 259 (2026-10-23); since then each session writes its own record in `docs/progress/`, so two sessions running in parallel never edit the same file.

- **The records:** `docs/progress/<YYYY-MM-DD>-<branch>.md`, one per session, named as its session file in `docs/handoffs/sessions/`. The dated files sorted by name are the list, and the last of them is the newest record; the older `session-*.md` records sort after them.
- **The records written before choice 259:** listed in `docs/progress/index.md`, in the order they were written; the last one is `docs/progress/2026-10-23-choices-257-258.md`.
- **Where each numbered choice is stated:** `docs/progress/choices.md`, generated by `python tasks.py choices-index`.
- **How a session writes its record:** `HANDOFF.md`, "How a session ends".
