Cost: one entry in the phase table and one (e) incident fixture in the tests.

163. **A framework gap a design run exposes is fixed after the change's tag, not before the build, when it does not affect the gate's verdict.** The three gaps of this session are cosmetic or removed by the fix round's own reflow; a fix now would be a plugin change needing a bump, a tag and a pin before the build run could use it, and the change already claims 0.3.6.
