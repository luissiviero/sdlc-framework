## In five lines

- **The bar is a count, not a file.** Row A3 of the record said "the test count"; the breakdown turned it into "a deleted test file". A deleted file is one of several ways to lower the bar: a file emptied of its tests, a `-k`/`--deselect`/`testpaths` line in the runner's configuration, a `conftest.py` collection hook or an early `return` lower it with no file deleted and no marker added. Only a measured number catches them all. The number exists: `python -m pytest --collect-only -q -o addopts=` ends with `1618 tests collected`, and the test run with `29 passed` (verified, section 2).
- **A floor in `sdlc.yaml` is a target, not a ratchet.** ArtCraft's agents raise `FLOOR` themselves when parity grows (`photocraft AGENTS.md:89`); a run here may never edit `sdlc.yaml`, so a `min` there rises only by the owner's hand, and one set above what the code does would make every change red. The ratchet is the merge base's own value, measured by the same step on a clean checkout of HEAD: today that step runs on the working tree the session left, with no clean-tree guard between the session's gate and the run (section 7).
- **Row 5 does not work as the code stands.** `sdlc:accept-risk` accepts only the `risk_list` check's recorded hits (`plugin/state/unpark.py:68-84`, `:115-124`); a finding from a new check is "nothing to accept" until plugin code records it as a risk-list hit. Done that way, decision 24 is read, not amended; 11 and 21 are untouched (a deterministic check parks and never goes to the panel). Decision 29 decides rows 4 and 5 together: a ratchet run and judged in the commands step is a red target, so in CI, after R10, it starts a round instead of parking.
- **Row 2's patterns misfire both ways.** As substrings they fire on this repository's own `tests/test_detect_runbooks.py` (nine `--deselect` lines), on `pytest.skip(` platform skips in four test files, on filmcraft's `#[ignore]` perf tests and on `xfail(strict=True)`; and they miss every way of skipping that uses no marker. A list for the reviewer, not a park.
- **The port-list reasoning for row 4 does not survive, as it did not for A1.** The commands step is `gate.py`/`checks.py`; `run_phase.py` needs the one timeout line (`:1317`); HANDOFF's rule records a PR, it forbids none. The owner's expected split (files and plan first, the measured ratchet after) does match the code this time, with the corrections in section 6.
