# The sources of truth: where each kind of fact is written, its one owner, and the drift on `main` (2026-10-22, report only)

The owner asked for a study of the sources of truth in both repositories. It covers three things for each kind of fact: every place it is written, the one place that may hold its current value, and the stale copies on `main` today. The study changes no existing file except the ROADMAP row it adds. Its proposal is ROADMAP R65 (`docs/proposals/one-owner-per-fact.md`), a candidate and not a decision.

## Method
- **Repositories and commits.** Both repositories were fetched with full history. Every line number below is on framework `main` at `84c50a0` (#320) or sample `main` at `28fba16` (sample #99), unless the row names another ref (verified, `git log -1 origin/main` in each, re-read before writing).
- **Open PRs.** Read on their branches, not on `main`:
  - framework #321, session `ccr-76f1ceba-idf2w0`'s choice 251 as 1.0.23, opened while this study ran;
  - framework #173, intent 0004;
  - sample #55, change 0010.
- **How "every place" is reported.** The living places (code, configuration, guidance, command and skill texts, workflow comments, generated indexes, decisions and proposals) are listed one by one with `file:line`. The history places are the session files, `docs/PROGRESS.md`, `docs/progress/`, the reviews and the PR bodies. Choice 126 keeps them as written, so they are reported as a class: a count of matching lines and files, and the command that reproduces it (section 1.12). A per-line list of a few thousand history lines would be a copy of `git grep`, not a finding.
- **The PR bodies.** A sub-agent read the bodies of the last ten merged framework PRs (#320, #318, #319, #317, #316, #313, #315, #314, #312, #307) and the last five merged sample PRs (#99, #100, #92, #98, #97) through the GitHub API, with a brief that named the eleven kinds. This session read its report, not the bodies themselves; the counts in section 1.12 are its counts.
- **Where the line numbers come from.** Each one was read with `git show origin/main:<file> | sed -n <line>p` or `git grep -n` on `origin/main`. "Verified" below means one of those reads, a test or a byte comparison named beside it.

The classes of section 2, used in the tables below:
- **owner**: the one place that may hold the current value;
- **point**: says where the value is, without the value;
- **generated**: written by a task from the owner;
- **linted**: a copy that a check compares with the owner;
- **history**: append-only (choice 126), annotated and never rewritten;
- **delete**: should not exist;
- **copy**: a copy with no generator and no check today. Each copy row says which class it should move to.
