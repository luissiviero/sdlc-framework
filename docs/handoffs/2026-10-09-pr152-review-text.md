Skip git's global options before the verb the way `cp`/`mv`/`rm` skip flags (`_nonflag`), consuming the argument of `-c`, `-C`, `--git-dir`, `--work-tree`, `--namespace` and `--exec-path` when it is a separate token; a test per form, and the same forms in the `-C` resolution path (`_git_dash_c`), which must still see `-C <dir>` when another global option precedes it.
2. `_inner_shell_command`: only the adjacent pair (`bash`, `-c`) is recognised, so an interpreter flag between the program and `-c` skips the recursion — `bash --norc -c 'echo x > CLAUDE.md'`, `sh --posix -c '…'`, `pwsh -NoProfile -Command '…'`, `cmd /d /c '…'` are never parsed inside, while `bash -c 'echo x > CLAUDE.md'` yields `CLAUDE.md`. Find the `-c`/`/c`/`-Command` token after any flags, recurse into the next token; a test per interpreter.

3. `_part_targets` and `decide()`: a directory target never matches a protected pattern (`/.claude/**` needs a slash after `.claude`; `docs/policy.md` does not match `docs`), so a recursive delete or move of a guardrail directory, or of an ancestor of a `protected_paths` entry, is allowed — `python -c "import shutil; shutil.rmtree('.claude')"`, `git rm -r -q .claude`, `git rm -r -q docs`, `Remove-Item -Recurse -Force .claude` all `allow` (reproduced on a scratch project with `docs/policy.md` under `protected_paths`); `shutil.rmtree` is on the spec's own idiom list.
